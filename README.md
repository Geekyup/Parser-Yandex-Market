# yandex-market-parser

Парсер товаров с Яндекс Маркета. Асинхронные запросы через `curl_cffi`, обход TLS-фингерпринта, экспорт в `.xlsx`. Два режима запуска — консоль и GUI.

---

## Быстрый старт

```bash
pip install -r requirements.txt
python main.py
```

Или с графическим интерфейсом:

```bash
python gui.py
```

---

## Структура

```
yandex-parser/
├── main.py          # консольный запуск
├── gui.py           # GUI (tkinter)
├── config.py        # все настройки здесь
├── requirements.txt
└── app/
    ├── cookies.py   # загрузка .txt файла с куками
    ├── fetcher.py   # HTTP-слой, AsyncSession, семафор
    ├── parser.py    # парсинг HTML → список товаров
    └── storage.py   # сохранение в Excel
```

---

## Настройка

Все параметры — в `config.py`:

| Параметр | По умолчанию | Описание |
|---|---|---|
| `SEARCH_PARAMS` | `text: "ps 5"` | Поисковый запрос и фильтры |
| `OUTPUT_FILE` | `ps5_data.xlsx` | Куда сохранять результат |
| `CONCURRENCY` | `3` | Параллельных запросов |
| `DELAY` | `0.5` | Задержка между запросами (сек) |
| `DEFAULT_PAGES` | `10` | Страниц по умолчанию |

## Куки (опционально)

Без кук парсер работает, но Яндекс может ограничить выдачу или потребовать капчу. С куками — стабильнее.

1. Установи расширение [EditThisCookie](https://chrome.google.com/webstore/detail/editthiscookie) или аналог
2. Зайди на `market.yandex.ru` под своим аккаунтом
3. Экспортируй куки в формате **Netscape** (`.txt`)
4. Укажи путь в `config.py` → `COOKIES_FILE` или выбери файл в GUI

## Что собирается

| Поле | Описание |
|---|---|
| Название | Полное название товара |
| ID | Числовой ID товара на Маркете |
| Цена | Текущая цена (строка) |
| Рейтинг | Средняя оценка |
| Отзывы | Количество отзывов |
| Купили | Счётчик покупок |
| Ссылка | Прямая ссылка на товар |
